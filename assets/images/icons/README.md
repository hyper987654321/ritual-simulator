# UI Icons

Source images live in `source/` at 1024x1024.

Roblox-ready resized outputs live in:

- `roblox/256/` for uploaded UI image assets
- `roblox/128/` for medium UI previews
- `roblox/64/` for small buttons

Regenerate outputs with:

```powershell
python assets\images\icons\resize_icons.py
```
